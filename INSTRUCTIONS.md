# Wayfis — Система Автодоната

## Инструкция по эксплуатации

---

### 1. Установка

**Требования:**
- Node.js 18+
- MySQL

**Шаги:**
1. Скопировать папку `hipexmc-shop` на сервер
2. В `.env` указать данные БД (если стандартные — ничего менять не нужно)
3. Установить зависимости:
   ```
   npm install
   ```
4. Инициализировать БД:
   ```
   node db-init.js
   ```
5. Запустить магазин:
   ```
   node server.js
   ```
   Откроется на порту 3000 (http://localhost:3000)

**Для работы плагина на сервере Minecraft:**
1. Скопировать `plugin/target/WayfisDelivery.jar` в папку `plugins/` на сервере
2. Перезапустить сервер
3. Настроить `plugins/WayfisDelivery/config.yml` (api-key, http-port)

### 2. Админ-панель

**Вход:** `/admin`  
**Логин/пароль:** admin / admin123 (можно изменить в `.env`)

#### Разделы:

**Обзор** — статистика: доход сегодня/неделю/месяц, кол-во заказов, график

**Каталог** — товары (добавить/редактировать/удалить)
- Поля: название, описание, цена, старая цена (для скидки), иконка, тип товара (quantity/single), категория, команды выдачи, видимость, бейдж, сортировка
- Тип `quantity` — игрок может выбрать количество
- Тип `single` — количество скрыто, только 1 шт.
- Команды: `{player}` — подставляется ник, `{quantity * N}` — N умножается на кол-во

**Категории** — группировка товаров на витрине (сортировка, видимость)

**Витрина (FAQ)** — вопросы-ответы, отображаются на главной

**Акции** — промокоды (тип скидки: % или фикс., макс. использований, срок действия)

**Финансы** — заказы (статус, поиск по нику, пагинация 50/стр.), ручное завершение, просмотр деталей

**Выдача** — настройка способа выдачи товаров на сервер
- **RCON**: хост, порт (обычно 25575), пароль (из `server.properties`)
- **Плагин**: URL плагина (`http://ip:19132`), API-ключ
- Вкладка показывает статус подключения (подключено/не подключено)
- Кнопка «Тест плагина» — отправляет тестовую команду на сервер

**Оплата** — настройка 4 платёжных систем:
- **YooKassa**: Shop ID + Secret Key
- **Platega**: API URL + Shop ID + API Key
- **UnitPay**: Public Key + Secret Key
- **Free-Kassa**: ID магазина + Секретные слова #1 и #2
- Каждую можно включить/отключить
- Webhook URL генерируется автоматически

**Настройки** — общие настройки магазина:
- Название, описание, заголовок
- IP сервера, версия, режим
- Акцентный цвет, цвет фона
- Hero-заголовок, соцсети, подвал
- Макс. онлайн (для прогресс-бара)

**Аудит** — лог всех действий в админке (кто, что, когда)

### 3. Публичный магазин

Главная страница (`/`):
- Hero-блок: заголовок, IP сервера (кнопка копирования), онлайн (живое обновление каждые 30с)
- Категории: фильтр товаров по категориям
- Товары: карточки с ценой, иконкой, описанием; кнопки «В корзину» и «Купить сразу»
- О сервере: описание, версия, режим, онлайн
- FAQ: раскрывающиеся вопросы-ответы
- Подвал: ссылки на соцсети, Terms, Privacy

Страница товара (`/product/:id`):
- Картинка, название, цена, количество (для quantity), поля: ник, промокод
- Пользовательское соглашение (модальное окно с кнопками Принять/Отказаться)
- «В корзину» / «Купить сразу»

Корзина:
- Список выбранных товаров с количеством
- Поле ника, промокода
- Кнопка «Оплатить» → открывает соглашение → редирект на платёжную систему

Профиль (`/profile/orders`):
- Поиск заказов по нику
- Список оплаченных заказов

Другие страницы: `/terms`, `/privacy`, 404

### 4. Платежи

**Порядок приоритета:** YooKassa → Platega → UnitPay → Free-Kassa
(система пытается использовать по очереди, переключается на следующую если не получилось)

**Webhook URL (для уведомлений):**
- YooKassa: `http://ваш-сайт/pay/webhook/yookassa`
- Platega: `http://ваш-сайт/pay/webhook/platega`
- UnitPay: `http://ваш-сайт/pay/webhook/unitpay`
- Free-Kassa: `http://ваш-сайт/pay/webhook/freekassa`

Если ни одна платёжка не настроена — заказ завершается без оплаты (режим теста).

---

### 5. Мониторинг

**Онлайн** — запрашивается с `api.mcstatus.io/v2/status/java/{ip}` каждые 60с с кэшированием.
IP берётся из настроек магазина (поле «IP сервера»).

**Фоновый планировщик** — каждые 60с проверяет зависшие заказы (pending > 2 мин), запрашивает статус платежа через API платёжной системы и завершает оплаченные.

### 6. Плагин (WayfisDelivery)

**Порт:** по умолчанию 19132  
**Эндпоинты:** `/health`, `/execute` (POST)  
**Аутентификация:** Bearer token (api-key)  
**Команды:** `{player}` → ник игрока, `{product}` → название товара

Плагин принимает команды от магазина через HTTP и выполняет их на сервере.

### 8. Частые проблемы

**Онлайн показывает 0:**
- Проверить IP сервера в Настройках
- Сервер должен быть доступен для пинга из интернета
- `api.mcstatus.io` должен быть доступен (не заблокирован)

**Плагин не отвечает:**
- Порт 19132 открыт в фаерволе?
- Плагин загружен и работает (`/plugins` в консоли сервера)
- В конфиге плагина правильный api-key, в админке такой же

**Платёж не приходит:**
- Webhook URL должен быть доступен из интернета
- Настроены правильные ключи в админке
- Включён нужный способ оплаты

**Не сохраняются настройки:**
- MySQL запущен и доступен
- Таблица `shop_settings` существует (`node db-init.js` если нет)
